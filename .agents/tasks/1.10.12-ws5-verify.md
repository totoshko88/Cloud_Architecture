## What changed

- **Return bus, layout router** (`layout/routers.py::_route_return_bus`, `route_back_edge(bus=)`, `route_edge(bus=)`). A leftward / response edge runs on a lane OUTSIDE every content row it spans: the band above the topmost icon in its x-span, or below the lowest footprint, inside the innermost container holding both ends (below its caption strip, above its bottom border). Rise in the gap right of the source; top drop (free drop column when stacked) or a lane in the gap left of the target into its left face. Lanes share the `hcorr-<side>:<row>` namespace.
- **Return bus, scored search** (`layout/variants.py`): `RETURN_BUS_ABOVE` / `RETURN_BUS_BELOW` plans, family `return-bus-{above-top, above-left, below-left}` for a return edge (target centre left of the source) of class `back-edge` or `cross-region` (covers the Theme 11 callback to an external actor). Right exit (Variant A), flagged `face_swap` so the solver takes a bus only on strictly fewer crossings with no new rule finding; kept out of the most-constrained-first key (`faces=False`). `solver._BUS_SIDE` maps the plan to the router.
- **Return bus, finishing pass** (`crossing_repair.py`): `bus_shapes` (rise column + bus lane outside the content rows + top drop or left lane) added to the repair family (`_ranked`, `side=True`); not to `avoidable_crossings` (`Xav` stays the single-face-swap measure). The joint search adds the best candidate of each route shape the ink-ranked pool left out (`_diverse`, ≤ 40 per member), which is what lets two replies leaving one node nest (05 e3 / e7).
- **Lint** (`linter.py`, documented in `diagram-lint.md` table + detail + Diagram Class row):
  - `flow-step-undrawn` (WARNING, both classes): a numbered Flow step no edge marker carries; exempt when the line contains `(not drawn)`. Reason `undrawn-steps:<N,...>`, offenders `step-<N>`.
  - `graph-islands` (WARNING, landscape only): connected nodes in more than one component (`geometry.graph_components`; edge-less and overlay-marked nodes left out). Reason `islands:<n>`, offenders = nodes outside the largest component.
- **`supporting` overlay** (`diagram_layout._OVERLAY_SHAPE`, dotted `dashPattern=1 3`; `OVERLAY_LEGEND_LINES` + `overlay_legend_lines(nodes)` give the standard Legend line). Exempt from `node-connectivity` (as every overlay term already is) and from `graph-islands`; `overlay-legend-coverage` requires the Legend entry. `diagram-standards.md`: overlay table row + `supporting` paragraph + *Return flows ride the return bus* paragraph.
- **SEP fixture specs** (content only, `tests/fixtures/sep/scripts/`): 05 e7; 06 e7, e10, e11; 07 e8, e9 drawn again; 09 e17 drawn, e24 LMS → API Gateway, e25 SQS → Syndicate Server, e26 Syndicate Server → sandbox fleets added (Flow 24–26, step 4 / 21 text split), LMS before Keycloak in the identity band (e4 now LMS → Keycloak), and the builder's band-left-edge alignment applied only when the bands really are stacked in one column. Committed fixture `.drawio` files stay the WS0 baseline, as in WS2–WS4.
