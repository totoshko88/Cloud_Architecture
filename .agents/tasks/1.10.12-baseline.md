## Columns

The metric definitions live in the script's docstring. In short:

- `N/E`: nodes / edges. `bbox`: model bbox of icons, captions, containers, text cells and waypoints. `page`: `SHORT` when `pageWidth`/`pageHeight` do not cover the bbox (C14).
- `util`: coverage as the `canvas-quality` lint defines it. `ler_out`: largest empty rectangle on the canvas, with % of bbox. `ler_in`: largest empty rectangle inside any container (C9).
- `X`: crossings, counted like `route_cost`. `Xav`: crossings removed by greedy single-edge legal face swaps (C7).
- `back`: leftward edges (C6). `own`: edges cutting their own source/target caption (C1). `col`: collinear pairs (C5). `capovf`: container caption wider than its box (C4). `undrawn`: Flow steps with no edge marker (C2).
- `comp/orph`: connected components / degree-0 nodes (C2/C3). `sib same/raw`: sibling container width/height spread, among siblings with equal node count / overall (C8).

## C12 repro (06 v3, `atlas sub=2`)

- `tests/fixtures/sep/repro/06v3-flow-task-verification.drawio` is the historical v3 output (title `… | 2026-10-15 | v3`), copied from SEPARCH `.agents/tasks/_regen7_prior/`.
- `tests/fixtures/sep/repro/06v3-atlas-sub2.drawio` is regenerated by `tests/fixtures/sep/scripts/build_06v3_atlas_sub2.py`: the v4 spec with `atlas` set back to `sub=2`. Its e8 route and every metric match the historical file.
- The defect itself: `e8` (`lti -> atlas`) runs `(580,160) -> (580,360) -> (1390,360) -> (1390,440)`. S3 is at x 1130..1208, y 360..438, so the 810 px horizontal leg lies exactly on S3's top border. `segment_crosses_box` (inset 2) returns False; at inset 0 it returns True. That is why `knee-through-*` stays silent. None of the WS0 metrics count this case. WS7's acceptance is the lint finding on this file.
