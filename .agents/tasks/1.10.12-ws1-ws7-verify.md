## What changed

WS1, raster scale (`src/rule_engine/export_raster.py::compute_scale`):

- `scale = min(MAX_EXPORT_SCALE=1.5, (class_budget - 2*border) / W)`. The class budgets stay 1600 (flow) and 3600 (landscape). The 1600/3400 TARGET widths are removed.
- The fit term is below 1 only when the canvas is over its budget. Such a canvas is now fitted down automatically for flows too, so `--max-width` is no longer needed. Below the 0.5 legibility floor (`MIN_EXPORT_SCALE`, which was the landscape-only `LANDSCAPE_MIN_SCALE` and is kept as an alias) the export still raises `CanvasTooWideError` ("split the diagram").
- `--max-width` keeps working: the same formula with the override as the budget and no floor.

WS1, page size (`src/rule_engine/diagram_layout.py::_cover_page`, `geometry.content_bbox`):

- `build_diagram` measures the finished document with the linter's parser. The bbox covers containers, text cells, node icons with their captions, and edge contacts/waypoints, the same definition as `canvas_metrics.py`. Each page axis is raised (never lowered) to the content edge + `CONTAINER_PAD`, rounded up to the grid. A page that already covers its content is byte-identical. Every builder path goes through `build_diagram` (draw_cli, example builders, SEP scripts).

WS7, edge through icon (`src/rule_engine/geometry.py`):

- `segment_rides_box_border`: an axis-aligned leg drawn on an icon border is flagged when it is at most 2px inside the box (the band the 2px inset of `segment_crosses_box` ignores) or at most 1px outside (half the 1.5pt stroke, rounded up) and overlaps the border by at least one grid step.
- `check_edge_routing` applies it to both the straight and the knee checks, under the existing `straight-through-*` / `knee-through-*` reasons, so the finding is an ERROR. The scored objective (`rule_violations`) sees it too.
- `marker-label-collision` gains a reason `marker-on-icon` (`geometry.check_marker_icon_collision`, WARNING): the marker anchor falls inside a node's icon box. `marker-on-caption` is unchanged.
