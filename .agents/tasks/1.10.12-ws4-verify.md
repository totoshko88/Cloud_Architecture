# WS4 verification — automatic flow-aware ordering (C6)

Plan: `.agents/tasks/1.10.12-engine-plan.md` WS4, decision 3 (automatic, on by default; explicit pins respected; `order: manual` opts out; goldens re-baselined with the guard "no golden gets more crossings or back-edges"). Numbers: `.agents/tasks/1.10.12-metrics.md`, section *WS4*.

## What changed

- `src/rule_engine/layout/ordering.py` (new). Wraps the default `layout()` path (`pipeline.layout` → `order_and_place`). Moves, all coordinate-free spec transforms that never touch `sub`:
  - `reorder`: permute the slots of the unpinned nodes of one group (same lane, sub-row, container; peer regions `a`/`b` jointly so the mirror holds). Barycentre seed (2 passes), then exhaustive permutations for groups of 5 or fewer (pairwise swaps above that), each with a one-step lookahead (re-seed the other groups).
  - `shift`: open up to two one-slot gaps in a North–South lane of account-level nodes (a band moves under the node that feeds it).
  - `relane`: a left→right account-level node that sits before its producer moves to the nearest occupied lane after every producer and before every consumer. Only accepted when it removes a back-edge.
  - `vpc_side`: second search start with the network block right of the regional column that feeds it.
- Objective: proxy search on the placement-only pipeline, key `(back-edges, hooks, lines through an icon, crossings, length)`. Only when the proxy finds fewer back-edges are up to three orders laid out in full, screened on their raw geometry, and the best two measured after the `build_diagram` finishing passes (caption-safe + crossing repair, real labels). Kept only when finished back-edges and crossings are both ≤ the declared order, one strictly lower, and no new rule ERROR, own-caption cut (WS2) or collinear pair (WS8). The declared order wins every tie. A declared order with more than 20 raw crossings is kept as is (`FINISH_BUDGET`, checked before any candidate is laid out): the finishing measurement costs minutes there (the quick-1.10.0 landscape fixture, 44 raw crossings: 161 s per measurement). The SEP fixtures peak at 7 raw crossings.
- `NodeSpec.pinned` (new, default `False`): explicit slot pin. A non-zero `sub` also pins the slot; `sub` itself is never changed.
- `DiagramSpec.order` (`"auto"` default | `"manual"`): `manual` skips the module entirely.
- `DiagramSpec.vpc_side` (`"auto"` default | `"left"` | `"right"`): `base._place_base` places the banded network block right of the last regional column that feeds it and shifts later regional columns right; `auto` = `left` unless the ordering picks `right`. Validated in `_validate_spec`.
- `PlacedDiagram.order_report`: one line per change, a `why:` line naming the back-edges removed or introduced, and the verdict with finished back-edges / crossings / rule errors / own-caption cuts / collinear pairs before → after.
- `rule-engine-advise SPEC [--json]` (new console script, `src/rule_engine/advise_cli.py`): SPEC = a `.json`/`.yaml` DiagramSpec mapping, `module.py:NAME`, or a builder script (its `build()`/`main()` runs with `layout` intercepted). Prints `order_report`; writes nothing.
- `layout/repair._serialize_candidate(cand, labels=None)`: optional display labels (default behaviour unchanged).
